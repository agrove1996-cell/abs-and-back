ABS & BACK — Ali's 4-minute routine

What it does
- ABS: Elevated Crunches, Twisting Crunches, Supine Bicycle, The Hundred — 30 seconds each.
- BACK: randomly chooses 4 different exercises from the 8 supplied — 30 seconds each.
- 5-second Get Ready countdown, automatic changes, sound/haptic cues, pause/previous/next.
- Installable as an iPhone Home Screen web app and cached for offline use after first load.

To test on a computer
Open index.html in a browser. (The service worker/offline install requires HTTPS hosting.)

To put on iPhone
Upload these files to any simple static HTTPS host (GitHub Pages, Cloudflare Pages, Netlify, etc.).
Then open the resulting site in Safari → Share → Add to Home Screen.

No account, analytics, ads, subscription or external dependencies.
